# 数学复核

## 建立覆盖记录

- 收录关键编号及未编号公式、算法更新式、定理、引理、命题、推论及相关附录。其余公式至少核对定义、维度和上下文。以公式号、定理号或章节加公式锚点定位，列表记录“推导成立”“发现错误”“待核验”及依据。
- 建立符号与假设表，检查定义域、维度、索引、转置与逆或伪逆的条件、范数含义和跨节复用。检查目标、约束、可行性和物理意义是否对应。用作者明确写出的假设开始验证，清楚标出需要额外补充的假设。

## 独立验证

- 对关键公式抄录原式与前提，从定义或已验证结论独立推导。记录每步等号或不等号的依据、成立条件和维度，在首次无法成立的位置说明对后续结果的影响。对错误给出完整可核对的修正推导，无法补全时写明缺口、所需条件或最小可行修正。
- 按稿件内容检查梯度与矩阵求导、拉格朗日符号约定、KKT 的必要性或充分性及适用条件、对偶性、谱界、Lipschitz 条件、强凸性和更新式与目标的对应。对复合、随机或分布式算法检查相关误差项、期望或条件期望及算子假设。
- 对每个定理类声明核对完整假设、结论、证明路径、用到的外部结论及其条件。检查逻辑跳跃、循环引用和遗漏的边界情况。对可疑结论尝试构造满足原假设的低维反例，明确给出它违反哪一项结论。既未证成也未证伪时记为待核验，并写明卡在哪一步。
- 核对收敛对象和形式，包括目标值、迭代点、梯度范数或残差，逐条核对步长、迭代有界性、Lyapunov 函数、递推与速率的推出过程。核对是否混用了确定性、期望和几乎必然结论，以及复杂度口径和常数依赖。

## 数值辅助与回报

可执行且有诊断价值时用 Python 或 MATLAB 做有限差分、低维反例、假设边界测试或简单迭代。记录运行条件、关键输入、容差、种子与实际结果。数值通过仅对已测试输入提供辅助证据。没有运行时把脚本或算例标作验证建议。

每个数学发现附原式、出错步骤、推导或反例、修正建议和受影响的后续结果。记录作者确认前的拟改内容，供修订时保护技术含义，并在后续审稿时追踪。
