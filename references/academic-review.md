# 学术审查

1. 在摘要、引言和结论中列出主要贡献声明，将每条声明连到研究缺口、方法组件、理论结论和对应实验。检查研究问题、优化目标、实验评价指标和最终声称解决的问题是否一致。指出证据缺口与过强措辞，有依据时给出可替换的英文表述。
2. 审查文献综述是否准确定位研究差异。区分稿内已有证据与需要外部核实的新颖性判断。需要判定现有方法、引用或目标期刊规范时核对原始论文或期刊官方资料，标明来源与可核验范围。
3. 检查建模假设的物理或工程含义、约束和算法机制，找出可能影响正确性的数学线索并给出公式或定理的编号。将独立推导留给数学复核。
4. 审查实验基线的代表性和公平性、数据划分和重复设置、主要参数、指标、消融、复杂度和复现信息。结合实际贡献决定哪些补充实验有用。跨正文和图表核对结果、单位和数量级，说明实验究竟支持哪条主张。缺少原始数据或代码时标明能检查的范围。
5. 报告先列最可能改变主要结论的判断，再列逐项证据和修改方法。给出适用范围、需要作者补充的材料与修改优先级。缺失实验和引用以待补或待核验记录。
